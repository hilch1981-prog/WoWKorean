# CoA 클라이언트 선택 글꼴 패치

CoA의 기본 글꼴을 참조하는 화면에서 한글이 네모로 보이면 적용할 수 있는 별도 ZIP입니다. 한글 글리프를 포함한 나눔고딕을 기존 기본 글꼴 파일명으로 제공합니다. 해당 글꼴을 사용하는 일부 영문 UI의 서체도 달라집니다.

1. CoA 클라이언트를 종료합니다.
2. 게임 폴더에 이미 `Fonts`가 있으면 복사해 보관합니다.
3. ZIP의 `Fonts`를 `Ascension.exe`가 있는 폴더에 풉니다. 기존 글꼴에서 덮어쓴 파일은 복원할 수 있도록 기록해 두세요.
4. 게임을 다시 시작합니다. 복구할 때는 패치로 추가한 파일을 제거한 뒤 보관한 글꼴을 복원합니다.

이 ZIP의 동작은 해당 CoA 클라이언트가 게임 폴더의 `Fonts`를 읽는지에 따라 달라집니다. WoWKorean의 애드온 ZIP은 자체 글꼴을 포함하고 있어 이 패치 없이도 설치할 수 있습니다.

글꼴 출처는 [나눔고딕](https://github.com/google/fonts/tree/main/ofl/nanumgothic)이며 ZIP에 SIL Open Font License 전문이 들어 있습니다.
